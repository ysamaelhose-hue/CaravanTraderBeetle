С чего начать

Where to start

Эта wiki теперь открывается сразу со страницы Старт. Сначала делается один файл с вашим SteamID64, потом почти вся настройка уже идёт через TRB_AdminTool прямо в игре.

This wiki now opens directly on the Start page. First, set your SteamID64 in one file, then almost all normal setup is done in game through TRB_AdminTool.

Коротко

Short version

1. Один раз запустить сервер. 2. Вписать свой SteamID64 в admin.json. 3. Перезапустить сервер. 4. Выдать себе TRB_AdminTool и дальше работать уже из админки.

1. Start the server once. 2. Put your SteamID64 into admin.json. 3. Restart the server. 4. Give yourself TRB_AdminTool and do the rest from the admin menu.

Что делать после входа

What to do after access

Обычный первый путь такой: Создать трейдера здесь или Создать бродячего трейдера, потом открыть Управление трейдерами, выбрать NPC и уже там настроить Общие, Категории, товары, цены и валюту.

A normal first workflow is: Create trader here or Create wandering trader, then open Manage traders, select the NPC and configure General, Categories, items, prices and currency there.

  1. 1
    Установите CF, Dabs Framework и Caravan Trader Beetle, затем один раз запустите сервер, чтобы мод создал свои файлы профиля.
    Install CF, Dabs Framework and Caravan Trader Beetle, then start the server once so the mod can generate its profile files.
  2. 2
    Остановите сервер и откройте profile/Beetle/trader/config/admin.json.
    Stop the server and open profile/Beetle/trader/config/admin.json.
  3. 3
    В поле PrimaryAdminSteamId впишите свой полный SteamID64 из 17 цифр. Не короткий профильный ID, а именно полный SteamID64.
    Put your full 17 digit SteamID64 into PrimaryAdminSteamId. Use the full SteamID64, not a short profile ID.
  4. 4
    При необходимости добавьте и другие SteamID64 в AdminSteamIds, но для первого запуска обычно достаточно только главного администратора.
    If needed, add more SteamID64 values to AdminSteamIds, but for a first setup the primary administrator is usually enough.
  5. 5
    Запустите сервер снова. Через VPP, COT или другую админку заспавните себе предмет TRB_AdminTool.
    Start the server again. Spawn TRB_AdminTool for yourself using VPP, COT or another admin tool.
  6. 6
    Возьмите TRB_AdminTool в руки и используйте действие открытия админки Trader Beetle.
    Hold TRB_AdminTool in your hands and use the Trader Beetle admin action.
  7. 7
    Дальше настройка уже идёт в игре: создаёте торговца, добавляете категории, товары, валюту и только потом проверяете всё обычным игроком.
    After that, setup continues in game: create the trader, add categories, items and currency, then test everything as a normal player.

PrimaryAdminSteamId

Главный постоянный администратор Trader Beetle. Именно этот SteamID получает полный доступ к настройкам.

The primary permanent Trader Beetle administrator. This SteamID receives full configuration access.

Практика: после первого запуска дополнительных администраторов уже удобнее добавлять через внутриигровое меню Доступ.

Practical use: after first setup, additional administrators are easier to add through the in-game Access menu.

AdminPassword

Необязательный пароль для временного входа в админку в текущей игровой сессии.

Optional password for temporary admin access during the current game session.

Практика: обычному серверу он не нужен, если все администраторы добавлены по SteamID64.

Practical use: a normal server usually does not need it when all administrators are configured by SteamID64.

Если TRB_AdminTool не открывает меню, почти всегда проблема в одном из трёх мест: редактировали не тот профиль сервера, SteamID64 неполный или сервер не был перезапущен после изменения файла.
If TRB_AdminTool does not open the menu, the cause is usually one of three things: the wrong server profile was edited, the SteamID64 is incomplete, or the server was not restarted after the file change.
